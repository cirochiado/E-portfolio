# Cerco e Informo

Live site: https://cercoeinformo.it

WordPress project with work on layout, content structure, accessibility, forms and SEO.

## Source

- `css/style.css` — responsive layout and visual components
- `js/script.js` — mobile navigation, scroll reveals, cookie notice and newsletter consent checks
- `templates/front-page.php` — WordPress homepage template and recent-post query
- `snippets/contact-form.php` — Contact Form 7 validation and honeypot handling
- `snippets/newsletter-privacy.php` — MailPoet consent and privacy handling

The repository contains selected project code rather than a full WordPress installation.
